# Content calendar: 24 articles for the year after launch

Two a month. Each idea was checked against the pages already on the site: it answers a question no existing page owns, it supports an existing page with a link, and it does not target that page's primary keyword (brief §15.2).

Before writing each one: search the question as a person in Lagos would, note the top results and "People also ask" in `docs/serp-notes/{slug}.md`, add the keyword to `docs/keywords.csv`, then create the article in Keystatic (`npm run dev`, open `/keystatic`). Follow the article template: question as the heading, a 40–60 word answer first, follow-up questions as subheadings, a "When to see a dermatologist" box, references.
